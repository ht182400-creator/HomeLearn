# HomeLearn 测试环境搭建指南（新手版）

> ⏱️ 预计完成时间：**30 分钟**  
> 👤 适用对象：第一次搭建开发环境的新手  
> 🎯 目标：成功运行 HomeLearn 应用并登录测试

---

## 第一步：准备工作目录

打开 **PowerShell**（Windows 按 Win+X，选择"终端"或"PowerShell"），执行：

```bash
# 进入项目目录
cd d:\Work_Area\AI\HomeLearn

# 确认目录正确，执行后应显示当前路径
pwd
```

✅ **完成后应该看到**：`d:\Work_Area\AI\HomeLearn`

---

## 第二步：安装 Node.js

### 2.1 检查是否已安装

```bash
node --version
npm --version
```

**如果有输出**（如 v18.x.x），跳过 2.2，直接进入第三步。

**如果没有输出**，继续 2.2。

### 2.2 下载安装 Node.js

1. 浏览器打开：https://nodejs.org/
2. 点击绿色的 **LTS** 按钮下载
3. 运行安装程序，**一路点"下一步"直到完成**
4. 安装完成后**重新打开 PowerShell**（重要！）

### 2.3 验证安装

```bash
node --version
npm --version
```

✅ **预期输出**：
```
v18.x.x
9.x.x
```

---

## 第三步：安装 PostgreSQL 数据库

### 3.1 检查是否已安装

```bash
psql --version
```

**如果有输出**，跳过 3.2，直接进入 3.3。

### 3.2 下载安装 PostgreSQL

1. 浏览器打开：https://www.postgresql.org/download/windows/
2. 点击 **Download the installer**
3. 选择版本 **15** 或 **16**
4. 运行安装程序，设置密码为 **`postgres`**（记住这个密码）
5. 端口保持默认 **5432**
6. **一路点"下一步"直到完成**
7. 安装完成后会提示是否启动 Stack Builder，**选择否**

### 3.3 创建数据库

1. 按 **Win 键**，搜索 **"pgAdmin 4"** 并打开
2. 在左侧找到 **Servers** → **PostgreSQL 15**（或 16）
3. 右键 **Databases** → **Create** → **Database**
4. 填写：
   - Database: `homelearn`
   - Owner: `postgres`
5. 点击 **Save**

✅ **完成后应该看到**数据库 `homelearn` 出现在列表中

---

## 第四步：配置项目环境

### 4.1 复制配置文件

```bash
cd d:\Work_Area\AI\HomeLearn
copy .env.example .env
```

### 4.2 编辑配置文件

```bash
notepad .env
```

这会用记事本打开文件。**删除全部内容**，粘贴以下内容：

```env
NODE_ENV=development
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/homelearn?schema=public"
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=homelearn-secret-key-2026
```

**保存文件**（Ctrl+S），关闭记事本。

> ⚠️ 注意：如果第三步你设置的密码不是 `postgres`，请把上面 `DATABASE_URL` 中的 `postgres` 改为你设置的密码。

## 常见问题急救包

### ❌ 情况1：页面样式混乱（CSS 未加载）

**症状**：页面显示无样式，文字堆叠在一起

**原因**：Tailwind CSS 首次启动需要编译

**解决方法**：

1. **清除缓存重新编译**：
   ```bash
   # 停止服务器 (Ctrl+C)
   rm -rf .next
   npm run dev
   ```

2. **浏览器强制刷新**：
   - 按 **Ctrl + Shift + R**（Windows）
   - 或按 **Cmd + Shift + R**（Mac）

3. **检查浏览器 Network**：
   - 按 F12 打开开发者工具
   - 点击 Network 标签
   - 查找 `globals.css`
   - 状态应为 **200**（不是 404）

---

### ❌ 情况2：npm install 失败（网络超时）

```bash
# 清除缓存后重试
npm cache clean --force
npm install
```

### ❌ 情况2：提示 "无法连接到数据库"

1. 检查 PostgreSQL 服务是否运行：
   - 按 Win 键，搜索 **"服务"**
   - 找到 **postgresql-x64-15**（或 16）
   - 状态应该是 **"正在运行"**
   
2. 如果没有运行，右键 → **启动**

### ❌ 情况3：端口 3000 被占用

```bash
# 查找占用端口的进程
netstat -ano | findstr :3000

# 结束进程（假设 PID 是 12345）
taskkill /PID 12345 /F

# 重新启动
npm run dev
```

### ❌ 情况4：数据库密码错误

1. 打开 pgAdmin，确认数据库 `homelearn` 存在
2. 编辑 `.env` 文件，确保密码正确：
   ```bash
   notepad .env
   ```
3. 保存后重新执行：
   ```bash
   npm run db:push
   ```
