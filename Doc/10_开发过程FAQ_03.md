# 开发过程 FAQ

## Q01: Prisma Client 生成失败，文件被锁定

**问题描述**：运行 `npx prisma generate` 时报错 "The `prisma-client-js` query engine file was locked"

**原因**：有其他 Node 进程正在使用 Prisma Client

**解决方案**：
```powershell
# 1. 关闭所有 Node 进程
taskkill /F /IM node.exe

# 2. 清除 .prisma 缓存
Remove-Item -Path "node_modules\.prisma" -Recurse -Force

# 3. 重新生成
npx prisma generate
```

## Q02: 注册 API 创建默认学科失败

**问题描述**：用户注册时返回 500 错误，日志显示 "Unique constraint failed"

**原因**：`prisma.subject.createMany` 会因 `code` 字段唯一约束冲突而失败

**解决方案**：
在 `src/app/api/auth/register/route.ts` 中添加 `skipDuplicates: true`：
```typescript
await prisma.subject.createMany({
  data: [...],
  skipDuplicates: true,
});
```

**相关文件**：`src/app/api/auth/register/route.ts`

## Q03: 题目列表页面报错 "questions.filter is not a function"

**问题描述**：访问 `/dashboard/questions` 时页面报错

**原因**：API 返回 `{ questions: [...], pagination: {...} }`，但前端直接用 `setQuestions(data)` 设置整个对象，而不是 `data.questions`

**解决方案**：
在 `src/app/dashboard/questions/page.tsx` 中修复：
```typescript
// 错误写法
setQuestions(data);

// 正确写法
setQuestions(data.questions || []);
```

**相关文件**：`src/app/dashboard/questions/page.tsx`

## Q04: 题目管理页面加载失败

**问题描述**：访问 `/dashboard/questions/new` 页面被中止

**排查**：
1. 确认 `QuestionForm` 组件存在且路径正确 ✅
2. 确认开发服务器已重启
3. 检查控制台错误日志

**解决方案**：重启发服务器即可
