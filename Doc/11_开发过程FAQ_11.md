## CodeBuddy 模型配置 - 环境变量支持

### 功能说明

为了方便在不修改代码的情况下切换模型，CodeBuddy Native 实现支持通过环境变量配置默认模型。

### 修改内容

**修改文件**：`src/lib/codebuddy/codebuddy-native.ts`

## 注意事项

1. **环境变量优先级**：`chat(messages, model)` 调用时传入的 `model` 参数优先于环境变量
2. **默认值**：如果不配置 `CODEBUDDY_MODEL`，默认使用 `auto`
3. **模型有效性**：建议使用 `auto` 以获得最佳性能和成本优化
4. **配置生效**：修改 `.env.local` 文件后保存，Next.js 会自动热更新

## 🔧 变式题列表 API 500 错误修复

### 问题描述

访问 `/api/ai/similar/list?childId=xxx` 返回 500 Internal Server Error。

### 错误日志

```
Error: P2012: The relation field `child` on model `SimilarQuestion` is missing an opposite relation field on the model `ChildAccount`.
```

### 原因分析

Prisma schema 中 `SimilarQuestion` 模型定义了两条关系：
- `originalQuestion Question @relation(...)`
- `child ChildAccount @relation(...)`

但 `Question` 和 `ChildAccount` 模型缺少对应的反向关系字段。

### 修复方案

**文件**：`prisma/schema.prisma`

#### 1. 在 `Question` 模型中添加反向关系

```prisma
model Question {
  // ... 其他字段
  similarQuestions SimilarQuestion[]  // 举一反三变式题（新增）
}
```

#### 2. 在 `ChildAccount` 模型中添加反向关系

```prisma
model ChildAccount {
  // ... 其他字段
  similarQuestions SimilarQuestion[]  // 举一反三变式题（新增）
}
```

### 执行命令

```bash
# 同步数据库
npx prisma db push

# 重启开发服务器
npm run dev
```

1. 访问错题库页面：http://localhost:3000/dashboard/wrong-questions
2. 点击"查看变式题"按钮
3. 检查是否正常显示变式题列表（不再报 500 错误）

### 问题1：多选题答案输入区域

#### 修改内容

**文件**：`src/app/student/tasks/[id]/practice/page.tsx`

新增多选题分支 (`MULTIPLE_CHOICE`)，包含：

- **复选框视觉标识**：□ / ☑（选中时紫色背景 + 白色对勾）
- **实时反馈**：底部显示"已选：A、B、C..."
- **降级处理**：`metadata.options` 为空时自动降级为文本输入框

```tsx
{/* 多选题 - 多选按钮（带复选框） */}
{currentQuestion?.type === 'MULTIPLE_CHOICE' && (
  <div className="space-y-3">
    {/* 提示：多选 */}
    <p className="text-sm text-amber-600 font-medium flex items-center gap-1">
      <span>◆</span> 多选题（可选择多个答案）
    </p>
    {(() => {
      const options = currentQuestion.metadata?.options;
      
      // 如果没有 metadata.options，降级为文本输入
      if (!options || options.length === 0) {
        return (
          <textarea
            placeholder="请选择答案后输入（如：AB、ABC）..."
            value={answers[currentQuestion.id] || ''}
            onChange={(e) => handleAnswer(currentQuestion.id, e.target.value)}
          />
        );
      }

      const selected = (answers[currentQuestion.id] as string[]) || [];
      
      const toggleOption = (label: string) => {
        let newSelected: string[];
        if (selected.includes(label)) {
          newSelected = selected.filter(s => s !== label);
        } else {
          newSelected = [...selected, label];
        }
        handleAnswer(currentQuestion.id, newSelected.sort());
      };

      return options.map((option) => {
        const isSelected = selected.includes(option.label);
        return (
          <button onClick={() => toggleOption(option.label)}
                  className={`... ${isSelected ? 'border-violet-500 bg-violet-50' : ''}`}>
            {/* 复选框 + 标签 + 内容 */}
            <div className="flex items-start gap-3">
              <span className={`w-6 h-6 rounded border-2 flex items-center justify-center ...`}>
                {isSelected && <svg ... />} {/* 对勾图标 */}
              </span>
              <span className="font-bold mr-1 text-lg">{option.label}</span>
              <span dangerouslySetInnerHTML={{ __html: option.content }} />
            </div>
          </button>
        );
      });
    })()}

    {/* 显示当前已选 */}
    {(answers[currentQuestion.id] as string[])?.length > 0 && (
      <p className="text-sm text-violet-600 font-medium pl-2">
        已选：{(answers[currentQuestion.id] as string[]).join('、')}
      </p>
    )}
  </div>
)}
```

### 问题2：举一反三查询 childId 硬编码

#### 根因分析

`fetchSimilarQuestions` 函数中 `childId` 被硬编码为 `'default'`：

```tsx
// 修复前
const childId = 'default'; // TODO: 从任务信息中获取 childId
fetchSimilarQuestions(currentQuestion.id, childId);
```

#### 修复方案

1. **Task 接口添加 `childId` 字段**：

```tsx
interface Task {
  id: string;
  title: string;
  questionCount: number;
  allowSkip: boolean;
  questions: Question[];
  childId?: string;  // 关联的孩子ID（新增）
}
```

2. **使用 `task.childId` 替代硬编码**：

```tsx
{/* 修复后 */}
<Button
  onClick={() => {
    if (currentQuestion && task.childId) {
      fetchSimilarQuestions(currentQuestion.id, task.childId);
      setShowSimilarPanel(!showSimilarPanel);
    }
  }}
  disabled={!currentQuestion || loadingSimilar || !task.childId}
>
```

3. **增强变式题过滤条件**：

```tsx
// 只获取已完成且有有效内容的变式题
const validQuestions = data.data.filter(
  (sq: SimilarQuestion) =>
```

## 补全所有题型答案输入

### 修复前

只有 `SINGLE_CHOICE`、`TRUE_FALSE`、`FILL_BLANK`、`SHORT_ANSWER`、`CALCULATION` 有答案输入，其他题型（如 `PROOF`、`COMPREHENSIVE` 等）显示为纯文本，无法作答。

### 修复后

| 题型 | 类型 | 答案输入方式 |
|------|------|-------------|
| `SINGLE_CHOICE` | 单选题 | 选项按钮 |
| `MULTIPLE_CHOICE` | 多选题 | 选项按钮（多选）+ 复选框 |
| `TRUE_FALSE` | 判断题 | 选项按钮 |
| `FILL_BLANK` | 填空题 | 文本输入框 |
| `SHORT_ANSWER` | 简答题 | 文本输入框 |
| `CALCULATION` | 计算题 | 文本输入框 |
| `PROOF` | 证明题 | 文本输入框 |
| `COMPREHENSIVE` | 综合题 | 文本输入框 |
| `FREE_RESPONSE` | 解答题 | 文本输入框 |
| `COMPOSITION` | 作文 | 文本输入框 |
| `READING` | 阅读理解 | 文本输入框 |
| `LISTENING` | 听力题 | 文本输入框 |
| `OTHER` | 其他题型 | 文本输入框 |

### 代码实现

**统一文本输入分支**：

### 问题1：运行时错误 `join is not a function`

### 问题2：举一反三 API 认证问题

#### 问题描述

学生端点击"举一反三"后，API 返回 403 或显示"暂无相关变式题"。

#### 根因分析

`GET /api/ai/similar` API 只支持家长端 `auth()` 认证：
- 家长端 session：包含 `user.id`，查询 `ChildAccount` 验证归属
- 学生端 session：使用 `getChildSession()`，auth() 返回 null → 403

#### 修复方案

**文件**：`src/app/api/ai/similar/route.ts`

```typescript
// GET 方法改为双重认证
export async function GET(request: Request) {
  // 家长端认证
  const parentSession = await getServerSession(authOptions);
  // 学生端认证
  const childSession = await getChildSession();

  // 验证归属权限
  let hasPermission = false;
  if (childSession && childSession.child.id === childId) {
    hasPermission = true;  // 学生端访问自己的变式题
  } else if (parentSession?.user?.id) {
    const child = await prisma.childAccount.findFirst({
      where: { id: childId, userId: parentSession.user.id },
    });
    if (child) hasPermission = true;  // 家长端访问自己的孩子的变式题
  }

  if (!hasPermission) {
    return NextResponse.json({ error: '无权限访问该孩子的数据' }, { status: 403 });
  }

  // 查询增加 status: "COMPLETED" 过滤
  const similarQuestions = await prisma.similarQuestion.findMany({
    where: { childId, status: "COMPLETED" },  // 只返回已完成且有内容的
    // ...
  });
}
```

### 问题4：批量生成 JSON 解析容错（增强版）

#### 错误描述

生成变式题时控制台报错：
```
JSON解析失败: SyntaxError: Expected ',' or '}' after property value in JSON at position 841 (line 6 column 29)
```

#### 根因分析

AI 返回的 JSON 中包含 HTML 内容（如 `<br>`、`<p>` 标签），这些标签未转义直接放入 JSON 字符串值，导致 JSON.parse() 崩溃：

```json
{
  "content": "<p></p><p>选择合适的选项完成对话<br></p><p>Amy: Hi, Dad!...",
  //                                                              ↑
  //                                              HTML 中的 < > 导致 JSON 解析失败
}
```

#### 解决方案：双重保障

##### 1. 提示词优化（根本解决）

**文件**：`src/app/api/ai/similar/batch/route.ts`

在提示词中明确要求 AI 对 HTML 内容进行 JSON 安全转义：

```typescript
const SIMILAR_QUESTION_PROMPT = `...
【重要】JSON格式要求：
- 只返回纯JSON，不要包裹 markdown 代码块
- content 内容中的 HTML 标签必须转义：< 转为 \\u003c，> 转为 \\u003e
- 换行使用 \\n，不要使用 <br> 或 <p> 标签
- 双引号 " 转为 \\"
这样确保返回的 JSON 可以被标准 JSON.parse() 解析
...`;
```

##### 2. 接收端容错（兜底保障）

**文件**：`src/app/api/ai/similar/batch/route.ts`

##### 辅助函数

```typescript
/**
 * 修复 JSON 字符串中未转义的换行符和特殊字符
 * 在 JSON 字符串值中（双引号内），真实的换行需要被替换为 \n 字面量
 */
function fixJsonStringNewlines(jsonStr: string): string {
  let result = jsonStr;
  
  // 策略1：处理 HTML 内容中的 <br> 标签（转为 \n）
  result = result.replace(/<br\s*\/?>/gi, '\\n');
  
  // 策略2：处理 <p></p> 标签内的换行
  result = result.replace(/<\/p>\s*/gi, '\\n');
  
  // 策略3：处理双引号内的内容
  result = result.replace(/"([^"\\]*(?:\\.[^"\\]*)*)"/g, (match, content) => {
    let fixed = content.replace(/\r\n/g, '\\n').replace(/\n/g, '\\n').replace(/\r/g, '');
    fixed = fixed.replace(/&nbsp;/g, ' ');
    fixed = fixed.replace(/&lt;/g, '<');
    fixed = fixed.replace(/&gt;/g, '>');
    fixed = fixed.replace(/&amp;/g, '&');
    fixed = fixed.replace(/&quot;/g, '"');
    return `"${fixed}"`;
  });
  
  return result;
}

/**
 * 深度清理 JSON 字符串中的非法字符
 */
function deepCleanJson(jsonStr: string): string {
  let result = jsonStr;
  result = result.replace(/^\uFEFF/, '');
  result = result.replace(/[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]/g, '');
  result = result.replace(/^ +"/gm, '"');
  result = result.replace(/" +$/gm, '"');
  result = result.replace(/'([^']*)'/g, (match, content) => {
    return `"${content.replace(/"/g, '\\"')}"`;
  });
  return result;
}

/**
 * 备用解析：从非标准文本中提取 questions 数组
 * 使用正则尝试提取每道题目的关键信息，支持 HTML 内容
 */
function extractQuestionsFromText(text: string) {
  const questions: Array<{content: string; answer: string; analysis?: string}> = [];
  
  // 清理 HTML 标签，保留文本内容
  const cleanText = text
    .replace(/<br\s*\/?>/gi, '\n')
    .replace(/<\/p>/gi, '\n')
    .replace(/<[^>]+>/g, '')
    .replace(/&nbsp;/g, ' ')
    .replace(/&lt;/g, '<')
    .replace(/&gt;/g, '>')
    .replace(/&amp;/g, '&')
    .replace(/&quot;/g, '"');
  
  // 策略1：匹配标准 JSON 的 questions 数组项
  const jsonPattern = /"content"\s*:\s*"(.*?)"\s*,\s*"answer"\s*:\s*"(.*?)"(?:\s*,\s*"analysis"\s*:\s*"(.*?)")?/gi;
  let match;
  while ((match = jsonPattern.exec(cleanText)) !== null) {
    if (match[1] && match[1].trim().length > 0 && match[2] && match[2].trim().length > 0) {
      questions.push({
        content: match[1].replace(/\\n/g, '\n').trim(),
        answer: match[2].replace(/\\n/g, '\n').trim(),
        analysis: match[3] ? match[3].replace(/\\n/g, '\n').trim() : undefined,
      });
    }
  }
  
  // 策略2：如果没找到，尝试匹配 content/answer 模式
  if (questions.length === 0) {
    const qPattern = /(?:题目|content|题干)[：:]\s*([\s\S]*?)(?:答案|answer)[：:]\s*([\s\S]*?)(?=(?:解析|analysis|题目|content|题干)|$)/gi;
    while ((match = qPattern.exec(cleanText)) !== null) {
      if (match[1] && match[1].trim().length > 5 && match[2] && match[2].trim().length > 0) {
        questions.push({
          content: match[1].trim(),
          answer: match[2].trim(),
        });
      }
    }
  }

  if (questions.length === 0) {
    console.warn("[Similar] 无法从AI返回文本中提取有效题目");
    return { questions: [] };
  }

  console.log(`[Similar] 备用解析成功提取 ${questions.length} 道题目`);
  return { questions };
}
```

##### 完整解析流程

```typescript
let parsedContent;
try {
  // Step 1: 尝试提取 markdown 代码块中的内容
  const codeBlockMatch = aiContent.match(/```(?:json)?\s*([\s\S]*?)```/);
  if (codeBlockMatch) {
    aiContent = codeBlockMatch[1].trim();
  }

  // Step 2: 查找最外层 { ... } 对象
  if (!aiContent.trim().startsWith('{')) {
    const objMatch = aiContent.match(/(\{[\s\S]*?\})(?:\s*$|\s*[,\]])/);
    if (objMatch) {
      aiContent = objMatch[1];
    }
  }

  // Step 3: 深度清理 + 移除非法字符
  aiContent = deepCleanJson(aiContent);
  aiContent = aiContent
    .replace(/^\uFEFF/, '')
    .replace(/[\x00-\x09\x0B\x0C\x0E-\x1F]/g, '')
    .trim();

  // Step 4: 修复字符串内未转义的换行符和 HTML 标签
  aiContent = fixJsonStringNewlines(aiContent);

  parsedContent = JSON.parse(aiContent);

} catch (parseError) {
  console.error("JSON解析失败:", parseError, "\n原始AI返回长度:", aiContent.length);
  
  // Step 5: 最后尝试：正则备用解析
  try {
    parsedContent = extractQuestionsFromText(aiContent);
  } catch (fallbackError) {
    console.error("备用解析也失败:", fallbackError);
    parsedContent = { questions: [] };
  }
}
```

```
GET /api/docs/[name]
```

响应示例：
```json
{
  "success": true,
  "name": "11_开发过程FAQ_11.md",
  "content": "# 11_开发过程FAQ_11.md\n\n..."

```

### 功能特性

| 功能 | 说明 |
|------|------|
| 文档分类 | 按文件名自动分类（FAQ、需求分析、数据库、技术文档等） |
| 时间显示 | 显示文档创建时间和更新时间 |
| Markdown 渲染 | 支持标题、代码块、列表、表格等基本格式 |
| 复制内容 | 一键复制文档全文 |
| 响应式布局 | 适配手机和电脑屏幕 |
