## 001 - Question 模型缺少 Recording 反向关联

### 问题详情

**发现时间**: 2026-05-11 16:51:00

**错误信息**:
```
Error: Prisma schema validation - (get-dmmf wasm)
Error code: P1012
error: Error validating field `question` in model `Recording`: The relation field `question` on model `Recording` is missing an opposite relation field on the model `Question`. Either run `prisma format` or add it manually.
```

**影响范围**:
- `npm install` 执行失败
- `prisma generate` 无法生成客户端

**触发命令**:
```bash
npm install
```

---

### 问题原因

在 `prisma/schema.prisma` 文件中：

- `Recording` 模型定义了与 `Question` 的关系：
  ```prisma
  question      Question?       @relation(fields: [questionId], references: [id], onDelete: SetNull)
  ```

- 但 `Question` 模型中**缺少**对应的反向关系字段：
  ```prisma
  recordings    Recording[]     // ❌ 缺失
  ```

---

### 解决方案

**文件**: `prisma/schema.prisma`

**修改位置**: Question 模型（约第 200-206 行）

**修改前**:
```prisma
  user            User              @relation(fields: [userId], references: [id], onDelete: Cascade)
  subject         Subject           @relation(fields: [subjectId], references: [id])
  versions        QuestionVersion[]
  wrongQuestions  WrongQuestion[]
  questionTopics  QuestionTopic[]
  questionTags    QuestionTag[]
  attachments     Attachment[]
```

**修改后**:
```prisma
  user            User              @relation(fields: [userId], references: [id], onDelete: Cascade)
  subject         Subject           @relation(fields: [subjectId], references: [id])
  versions        QuestionVersion[]
  wrongQuestions  WrongQuestion[]
  questionTopics  QuestionTopic[]
  questionTags    QuestionTag[]
  attachments     Attachment[]
  recordings      Recording[]
```
