## 新功能说明

### 孩子独立登录功能

**功能概述：**
- 家长可以为每个孩子创建独立的登录账户
- 孩子使用自己的用户名和密码登录
- 孩子登录后只能看到自己的学习数据

**实现细节：**
1. **数据库修改**：`ChildAccount` 表添加 `username` 和 `passwordHash` 字段
2. **登录 API**：`/api/auth/child-login` 处理孩子登录
3. **会话管理**：使用 Cookie 存储孩子会话信息
4. **孩子界面**：`/student` 专属学习仪表板

**使用方式：**
1. 家长登录后，进入"孩子账户管理"
2. 添加孩子时，勾选"创建孩子独立登录账户"
3. 设置孩子的用户名和密码
4. 创建成功后，将登录信息告诉孩子
5. 孩子登录时选择"我是孩子"标签

### 孩子专属界面

**特点：**
- 简洁美观的卡片式设计
- 包含错题复习、AI问答、英语口语、学习报告
- 显示个人学习统计数据
- 根据时间段显示不同问候语

## 父母与孩子账户关联设计

### 数据模型关系

```
┌─────────────────────────────────────────────────────────────┐
│                         User (父母)                          │
│  - id, email, username, passwordHash                       │
│  - role: PARENT                                            │
│  - nickname, phone, avatar                                 │
│                                                             │
│  【一对多关系】                                             │
│  children: ChildAccount[] ──────────────────────────┐        │
└─────────────────────────────────────────────────────│────────┘
                                                      │
                                                      │ userId (外键)
                                                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    ChildAccount (孩子)                      │
│  - id, nickname, grade, avatar, gender, birthday          │
│  - username, passwordHash (独立登录凭证)                   │
│  - totalStudyTime, totalPractice, totalCorrect (学习统计) │
│                                                             │
│  【关联数据】                                               │
│  - wrongQuestions[] ←── 该孩子的错题                       │
│  - speechResults[] ←── 英语口语练习记录                    │
│  - reviewRecords[] ←── 复习记录                            │
│  - practiceRecords[] ←── 练习记录                           │
└─────────────────────────────────────────────────────────────┘
```

### 关联流程

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 家长注册/登录 | 创建 `User` 账户 |
| 2 | 添加孩子 | 在 `ChildAccount` 创建记录，`userId` 关联家长 |
| 3 | 创建登录账户 | 设置 `username` + `passwordHash` |
| 4 | 孩子登录 | 使用独立凭证，Session 与家长隔离 |
| 5 | 查看数据 | 孩子只看自己的 `ChildAccount` 相关数据 |

### 数据库设计

**User 表关键字段：**
```prisma
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  username  String   @unique
  passwordHash String
  role      UserRole @default(PARENT)
  
  // 关联
  children  ChildAccount[]
}
```

**ChildAccount 表关键字段：**
```prisma
model ChildAccount {
  id        String @id @default(cuid())
  userId    String  // 外键 → User.id
  nickname  String
  grade     Grade?
  avatar    String?
  
  // 独立登录凭证
  username    String? @unique  // 孩子登录用户名
  passwordHash String?         // 孩子登录密码
  
  // 学习统计
  totalStudyTime Int @default(0)
  totalPractice  Int @default(0)
  totalCorrect   Int @default(0)
  
  // 关联
  user          User @relation(...)
  wrongQuestions WrongQuestion[]
  practiceRecords PracticeRecord[]
  speechResults  SpeechResult[]
}
```

### 题目图片上传功能

**功能概述：**
- 富文本编辑器支持图片上传
- 图片转为 Base64 格式嵌入 Markdown
- 练习页面支持渲染 Markdown 图片

**实现细节：**
1. **编辑器组件** (`src/components/dashboard/rich-editor.tsx`)：
   - 添加图片上传按钮
   - 支持拖拽选择或点击选择
   - 文件大小限制 5MB
   - 图片转为 Base64 格式

2. **渲染支持** (`src/components/dashboard/practice-session.tsx`)：
   - 使用 `react-markdown` + `remark-gfm` 渲染
   - 支持 GFM 图片语法 `![alt](url)`

**使用方式：**
1. 在题目内容编辑器中，点击工具栏的"图片"按钮
2. 选择本地图片文件（支持 jpg、png、gif、webp 等）
3. 图片自动插入到光标位置
4. 保存后，图片以 Base64 格式存储

**注意事项：**
- Base64 格式会增加数据存储大小，建议单张图片不超过 2MB
- 大量使用图片可能影响加载性能
- 未来可考虑接入云存储服务（如 OSS、COS）优化性能

### Base64 图片渲染修复

**问题描述：**
- 预览时图片显示为破损图标
- 图片只显示文件名而非实际图片

**解决方案：**
1. 添加自定义 `MarkdownImage` 组件处理 Base64 图片
2. 检测图片 URL 是否以 `data:image/` 开头
3. 正确渲染 Base64 图片数据

**代码实现：**
```tsx
function MarkdownImage({ src, alt, ...props }) {
  if (src?.startsWith("data:image/")) {
    return <img src={src} alt={alt} className="max-w-full h-auto" />;
  }
  return <img src={src} alt={alt} />;
}
```
