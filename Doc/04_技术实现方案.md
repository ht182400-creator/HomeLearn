| 方案 | 服务商 | 免费额度 | 准确率 | 部署方式 | 延迟 | 成本 |
|------|--------|----------|--------|----------|------|------|
| **Mathpix Snip** | 第三方 | 100次/月 | **98%+** | 云API | <1s | ¥0 |
| MyScript | 第三方 | 有限免费 | 95%+ | SDK/云API | <2s | 付费 |
| 阿里云 OCR | 阿里云 | 500次/天 | 90% | 云API | <1s | ¥0 |
| 自训练模型 | 自建 | 无限 | 依赖训练 | 本地部署 | <2s | 算力成本 |

#### 推荐方案

**首选：Mathpix Snip API**

```typescript
// 实现示例
class FormulaRecognizer {
  private apiKey = process.env.MATHPIX_API_KEY;
  
  async recognize(imageBase64: string): Promise<string> {
    const response = await fetch('https://api.mathpix.com/v3/text', {
      method: 'POST',
      headers: {
        'app_id': process.env.MATHPIX_APP_ID,
        'app_key': this.apiKey,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        src: imageBase64,
        formats: ['latex'],
        include_lineboxes: true,
      }),
    });
    
    const data = await response.json();
    return data.latex;
  }
}
```

**备选方案：MyScript (离线优先时)**
- MyScript 提供离线 SDK
- 可在无网络环境使用
- 适合内网部署场景

```typescript
// AI 网关架构
class AIGateway {
  private adapters = new Map();
  
  // 注册多个适配器
  registerAdapter(name, adapter, config) {
    this.adapters.set(name, { adapter, config });
  }
  
  // 智能选择 + 负载均衡
  private selectAdapter() {
    const available = [...this.adapters.entries()]
      .filter(([, c]) => c.config.enabled);
    // 按权重随机选择
    const totalWeight = available.reduce((s, [, c]) => s + c.config.weight, 0);
    let random = Math.random() * totalWeight;
    for (const [name, { adapter, config }] of available) {
      random -= config.weight;
      if (random <= 0) return adapter;
    }
    return available[0][1].adapter;
  }
  
  async *chatStream(messages) {
    const adapter = this.selectAdapter();
    yield* adapter.chatStream(messages);
  }
}
```
