# 开发过程 FAQ

## Q01: Prisma Client 生成失败，文件被锁定

**问题描述**：运行 `npx prisma generate` 时报错 "The `prisma-client-js` query engine file was locked"

**原因**：有其他 Node 进程正在使用 Prisma Client

**解决方案**：
```powershell
# 1. 关闭所有 Node 进程
taskkill /F /IM node.exe

# 2. 清除 .prisma 缓存
Remove-Item -Path "node_modules\.prisma" -Recurse -Force

# 3. 重新生成
npx prisma generate
```

## Q02: 注册 API 创建默认学科失败

**问题描述**：用户注册时返回 500 错误，日志显示 "Unique constraint failed"

**原因**：`prisma.subject.createMany` 会因 `code` 字段唯一约束冲突而失败

**解决方案**：
在 `src/app/api/auth/register/route.ts` 中添加 `skipDuplicates: true`：
```typescript
await prisma.subject.createMany({
  data: [...],
  skipDuplicates: true,
});
```

**相关文件**：`src/app/api/auth/register/route.ts`

## Q03: 题目列表页面报错 "questions.filter is not a function"

**问题描述**：访问 `/dashboard/questions` 时页面报错

**原因**：API 返回 `{ questions: [...], pagination: {...} }`，但前端直接用 `setQuestions(data)` 设置整个对象，而不是 `data.questions`

**解决方案**：
在 `src/app/dashboard/questions/page.tsx` 中修复：
```typescript
// 错误写法
setQuestions(data);

// 正确写法
setQuestions(data.questions || []);
```

**相关文件**：`src/app/dashboard/questions/page.tsx`

## Q05: grades API 返回 500 错误

**问题描述**：调用 `/api/questions/grades` 返回 500 错误

**原因**：
1. `Grade` 在 Prisma Schema 中是**枚举类型**，不是数据库模型
2. API 代码错误使用 `prisma.grade.findMany()` 查询不存在的表

**解决方案**：
修改 `src/app/api/questions/grades/route.ts`，使用枚举值而不是数据库查询：
```typescript
import { NextRequest, NextResponse } from "next/server";

const GRADES = [
  { id: "PRIMARY_1", name: "小学一年级", level: 1 },
  { id: "PRIMARY_2", name: "小学二年级", level: 2 },
  // ... 其他年级
];

export async function GET(request: NextRequest) {
  try {
    return NextResponse.json({ grades: GRADES });
  } catch (error) {
    return NextResponse.json({ error: "获取年级列表失败" }, { status: 500 });
  }
}
```

**相关文件**：`src/app/api/questions/grades/route.ts`

## Q06: subjects API 返回 401 未经授权

**问题描述**：科目下拉列表为空，控制台显示 401 错误

**原因**：API 使用 `auth()` 检查 session，但题目录入页面加载时没有认证信息

**解决方案**：
修改 `src/app/api/questions/subjects/route.ts`，移除认证要求（学科是公共数据）：
```typescript
import { NextResponse } from 'next/server';
import prisma from '@/lib/db';

// 获取学科列表（无需认证，学科是公共数据）
export async function GET() {
  try {
    const subjects = await prisma.subject.findMany({
      orderBy: { order: 'asc' },
    });
    return NextResponse.json({ subjects });  // 统一返回格式
  } catch (error) {
    return NextResponse.json({ error: '服务器错误' }, { status: 500 });
  }
}
```

**相关文件**：`src/app/api/questions/subjects/route.ts`

## Q07: 前端 API 返回格式不一致

**问题描述**：前端期望 `data.subjects`，但 API 直接返回数组

**原因**：API 返回格式不统一

**解决方案**：
统一 API 返回格式为 `{ subjects: [...] }`：
```typescript
return NextResponse.json({ subjects });  // 不是 return NextResponse.json(subjects);
```

**相关文件**：
- `src/app/api/questions/subjects/route.ts`
- `src/app/api/questions/grades/route.ts`

## Q08: 验证 schema 缺少必要字段

**问题描述**：题目录入时总是提示 "创建题目失败"

**原因**：
1. `CreateQuestionSchema` 缺少 `gradeId` 和 `childId` 字段
2. `difficulty` 字段只接受数字，但前端传递字符串

**解决方案**：
修改 `src/lib/validators/question.ts`：
```typescript
export const CreateQuestionSchema = z.object({
  content: z.string().min(1, "题目内容不能为空"),
  type: QuestionTypeEnum,
  subjectId: z.string().min(1, "请选择科目"),
  gradeId: z.string().optional(),  // 新增
  childId: z.string().optional(),  // 新增
  difficulty: z.union([
    z.coerce.number().min(1).max(5),
    DifficultyEnum  // 支持字符串格式
  ]).default(3),
  answer: z.string().min(1, "答案不能为空"),
  explanation: z.string().optional(),
  tags: z.string().optional(),
});
```

**相关文件**：`src/lib/validators/question.ts`

## Q09: 题目创建 API 的 Json 字段类型错误

**问题描述**：题目创建失败，API 返回 500 错误

**原因**：
1. `content` 和 `answer` 字段是 `Json` 类型
2. 前端传递的是字符串，需要正确转换

**解决方案**：
修改 `src/app/api/questions/route.ts`：
```typescript
const question = await prisma.question.create({
  data: {
    content: validatedData.content as any,
    type: validatedData.type,
    subjectId: validatedData.subjectId,
    difficulty: typeof validatedData.difficulty === 'number' 
      ? validatedData.difficulty 
      : (validatedData.difficulty === 'EASY' ? 1 : validatedData.difficulty === 'MEDIUM' ? 3 : 5),
    answer: validatedData.answer as any,
    explanation: validatedData.explanation ? { text: validatedData.explanation } as any : undefined,
    userId: session.user.id,
  },
  include: { subject: true },
});
```

**相关文件**：`src/app/api/questions/route.ts`

## Q10: 题目列表页面的 subjects.map 错误

**问题描述**：`subjects.map is not a function`

**原因**：API 返回 `{ subjects: [...] }`，但前端直接设置 `setSubjects(subjectsData)`

**解决方案**：
修改 `src/app/dashboard/questions/page.tsx`：
```typescript
const fetchData = async () => {
  try {
    const [subjectsRes] = await Promise.all([
      fetch('/api/questions/subjects'),
    ]);
    const subjectsData = await subjectsRes.json();
    setSubjects(subjectsData.subjects || subjectsData || []);
    await fetchQuestions();
  } catch (error) {
    console.error('获取数据失败:', error);
  } finally {
    setLoading(false);
  }
};
```

**相关文件**：`src/app/dashboard/questions/page.tsx`
