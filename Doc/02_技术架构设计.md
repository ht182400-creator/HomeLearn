### 1.2 技术栈选型

| 层级 | 技术选型 | 选型理由 | 替代方案 |
|------|----------|----------|----------|
| **前端框架** | Next.js 14 (App Router) | SSR/SSG兼备，API Routes方便，BFF模式 | 纯React + Vite |
| **UI组件库** | TailwindCSS + shadcn/ui | 轻量、可定制、组件丰富 | Ant Design / Chakra UI |
| **状态管理** | Zustand + React Query | 轻量级、TypeScript友好 | Redux Toolkit |
| **数据库** | PostgreSQL 16 | 关系型、JSON支持、免费 | MySQL / SQLite(开发) |
| **ORM** | Prisma | 类型安全、自动迁移、IDE友好 | Drizzle / TypeORM |
| **文件存储** | MinIO (S3兼容) | 自建、兼容S3 API、量大后易迁移 | 本地FS / 云OSS |
| **缓存** | Redis | 会话缓存、速率限制 | 暂不用 / Memcached |
| **AI网关** | 自建适配器 | 统一接口、多API轮换 | LangChain / OneAPI |
| **语音服务** | 微软Azure (免费层) | 音素级评测、免费额度充足 | 腾讯云智聆 |
| **实时通信** | WebSocket (Socket.io) | AI对话流式输出 | Server-Sent Events |

### 3.3 服务层设计

```typescript
// 服务层示例 - 错题服务
class WrongQuestionService {
  constructor(
    private prisma: PrismaClient,
    private aiGateway: AIGateway
  ) {}
  
  // 获取错题列表 (带筛选)
  async list(params: ListWrongQuestionsDTO) {
    const { childId, subject, difficulty, mastered, dateRange, tags } = params;
    
    return this.prisma.wrongQuestion.findMany({
      where: {
        childId,
        question: {
          subjectId: subject,
          difficulty: difficulty ? { gte: difficulty, lt: difficulty + 1 } : undefined,
          tags: tags ? { hasSome: tags } : undefined,
        },
        mastered: mastered ?? undefined,
        createdAt: dateRange ? { gte: dateRange.start, lte: dateRange.end } : undefined,
      },
      include: { question: true },
      orderBy: { createdAt: 'desc' },
    });
  }
  
  // 苏格拉底式引导
  async socraticHelp(wrongQuestionId: string, userMessage: string) {
    const wq = await this.prisma.wrongQuestion.findUnique({
      where: { id: wrongQuestionId },
      include: { question: true },
    });
    
    // 构建提示词上下文
    const context = buildSocraticContext(wq.question, wq.attempts);
    
    return this.aiGateway.chat([
      { role: 'system', content: SOCRATIC_PROMPT },
      { role: 'user', content: userMessage },
    ], { userId: wq.childId });
  }
}
```

## 6. 安全架构

### 6.1 认证与授权

```
┌─────────────────────────────────────────────────────────────┐
│                     认证授权流程                             │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   用户 ──▶ 登录 ──▶ JWT Token ──▶ 访问受保护资源              │
│                    │                                        │
│                    ├── Access Token (15分钟)                │
│                    │    └── 存放在内存                        │
│                    │                                        │
│                    └── Refresh Token (7天)                   │
│                         └── HttpOnly Cookie                 │
│                                                              │
│   子账户登录 ──▶ 验证家长Token ──▶ 生成子账户Session          │
│                                                              │
│   权限检查 ──▶ 中间件层                                      │
│              │                                              │
│              ├── isAuthenticated()                          │
│              ├── isParent()                                  │
│              ├── isChild()                                   │
│              └── canAccessChild(childId)                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 6.2 数据隔离

```typescript
// 中间件: 确保孩子只能访问自己的数据
const childDataMiddleware = async (req, res, next) => {
  if (req.user.role === 'child') {
    req.query.childId = req.user.childId; // 强制覆盖
  }
  next();
};

// 路由: 获取错题
router.get('/wrong-questions', 
  authenticate, 
  childDataMiddleware, 
  async (req, res) => {
    // 所有查询自动带上 childId 限制
  }
);
```

### 6.3 API 安全

- **Rate Limiting**: Redis + sliding window，限制每IP/用户请求次数
- **CORS**: 仅允许自有域名
- **CSRF**: SameSite Cookie + CSRF Token
- **Input Validation**: Zod schema validation
- **SQL Injection**: Prisma ORM 参数化查询
- **XSS**: React自动转义 + CSP策略
