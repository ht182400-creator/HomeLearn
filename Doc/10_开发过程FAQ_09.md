## Tiptap富文本编辑器集成与问题修复

### 问题描述

在开发"新建题目"功能时，需要集成Tiptap富文本编辑器。功能包含三个主要编辑区域：
- 题目内容
- 答案
- 答案解析

每个区域都需要支持富文本编辑功能（加粗、斜体、删除线、代码、列表、引用、图片等）。

### 技术栈

- **编辑器框架**：Tiptap（基于ProseMirror）
- **前端框架**：Next.js
- **React**：用于组件开发

### 遇到的问题及解决方案

#### 问题一：SSR Hydration 错误

**错误现象**：
服务端渲染与服务端输出的HTML不一致，导致hydration失败。

**解决方案**：
在编辑器初始化配置中添加 `immediatelyRender: false` 选项：

```javascript
const editor = new Editor({
  content: initialContent,
  immediatelyRender: false,  // 解决SSR hydration错误
  extensions: [StarterKit, ...],
  onUpdate: ({ editor }) => {
    onChange(editor.getHTML());
  },
});
```

#### 问题二：BubbleMenu 导入错误

**错误现象**：
BubbleMenu 组件导入失败，提示模块不存在。

**解决方案**：
移除不必要的 BubbleMenu 组件，保持编辑器核心功能。

#### 问题三：客户端环境判断

**错误现象**：
服务端渲染时编辑器尝试访问浏览器API导致错误。

**解决方案**：
添加客户端挂载状态检查：

```javascript
const [isMounted, setIsMounted] = useState(false);

useEffect(() => {
  setIsMounted(true);
}, []);

// 在返回的JSX中
if (!isMounted) {
  return null;  // 避免SSR问题
}
```

### 完整配置代码

```javascript
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';

function RichTextEditor({ initialContent = '', onChange }) {
  const [isMounted, setIsMounted] = useState(false);

  useEffect(() => {
    setIsMounted(true);
  }, []);

  const editor = useEditor({
    extensions: [
      StarterKit,
      // 其他扩展...
    ],
    content: initialContent,
    immediatelyRender: false,
    onUpdate: ({ editor }) => {
      onChange(editor.getHTML());
    },
  });

  if (!isMounted || !editor) {
    return null;
  }

  return <EditorContent editor={editor} />;
}
```

### 总结

通过以下三个关键修复，成功解决了Tiptap编辑器在Next.js SSR环境下的集成问题：

## 新增问题修复

### 问题一：原生 alert 弹窗不友好

**问题描述：**
题目创建成功后使用原生浏览器 `alert()` 弹窗，样式简陋，用户体验差。

**错误代码位置：**
`src/components/dashboard/question-form.tsx` 第 175 行：
```typescript
alert(mode === "edit" ? "题目更新成功！" : "题目创建成功！");
```

**解决方案：**

1. **创建 Toast 组件** (`src/components/ui/toast.tsx`)：
   - 支持 success/error/info 三种类型
   - 美观的图标和颜色区分（绿色成功、红色错误、蓝色信息）
   - 自动 3 秒后消失
   - 支持手动关闭
   - 右侧滑入动画效果

2. **添加 ToastProvider** 到根布局 (`src/app/layout.tsx`)：
```tsx
import { ToastProvider } from '@/components/ui/toast';

// 在 RootLayout 中
<ToastProvider>
  {children}
</ToastProvider>
```

3. **替换原生 alert**：
```typescript
import { useToast } from '@/components/ui/toast';

const { showToast } = useToast();

// 替换 alert
showToast(mode === "edit" ? "题目更新成功！" : "题目创建成功！", "success");
```

## Prisma 字段使用规范

### 1. 区分标量字段和关系字段

```typescript
// ✅ 标量字段 - 直接访问
question.userId
question.grade
question.analysis

// ✅ 关系字段 - 需要 include
question.subject  // 需要 include: { subject: true }
```

### 2. 常见错误

```typescript
// ❌ 错误：标量字段用在 include 中
include: { grade: true }

// ❌ 错误：不存在的关系
include: { creator: true }

// ❌ 错误：使用错误的字段名
question.creatorId  // 应该是 question.userId
question.explanation // 应该是 question.analysis
```

### 3. 正确用法

```typescript
// 查询单个题目
const question = await prisma.question.findUnique({
  where: { id },
  include: { subject: true }, // 只 include 关系字段
});

// 查询列表
const questions = await prisma.question.findMany({
  where: { userId: session.user.id },
  include: { subject: true },
  orderBy: { createdAt: 'desc' },
});
```
