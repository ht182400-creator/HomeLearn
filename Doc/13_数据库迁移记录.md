## 迁移历史

### 2026-05-12 23:55 | PracticeTask 添加 answers 字段

**问题背景：**
- 确认任务 API 需要保存孩子的作答答案
- Schema 中 `PracticeTask` 模型定义了 `answers` 字段
- 但数据库表未同步该字段，导致报错：`Unknown argument 'answers'`

**Schema 变更：**

```prisma
// prisma/schema.prisma - PracticeTask 模型
model PracticeTask {
  // ... 其他字段
  answers              Json?         // 孩子的答案记录 {questionId: answer}
}
```

**SQL 执行语句：**

```sql
-- prisma/migrations/add_answers.sql
ALTER TABLE practice_tasks ADD COLUMN IF NOT EXISTS answers JSONB;
```

**执行命令：**

```bash
cd d:\Work_Area\AI\HomeLearn
npx prisma db execute --file prisma/migrations/add_answers.sql
npx prisma generate
```

**关联功能：**
- [功能 #14](./10_开发过程FAQ_10.md#功能-14家长确认时将未作答题目加入错题本)
- 家长确认任务时，将未作答和答错的题目加入学生错题本

### 2026-05-12 | 添加题目年级筛选和显示功能

**问题背景：**
- 需要在题目管理中添加年级筛选和显示功能
- Prisma Schema 中 `Question` 模型已有 `grade` 字段定义

**Schema 变更：**

```prisma
// prisma/schema.prisma - Question 模型
model Question {
  // ... 其他字段
  grade         Grade?          // 适用年级，不填=通用题
}
```

```typescript
// src/lib/validators/question.ts - QueryQuestionsSchema
export const QueryQuestionsSchema = z.object({
  // ... 其他字段
  grade: z.string().optional(),  // 新增年级筛选字段
});
```

**API 变更：**

| 文件 | 变更内容 |
|------|----------|
| `src/app/api/questions/route.ts` | GET 添加 grade 筛选，POST 保存 grade |
| `src/app/api/questions/[id]/route.ts` | PUT 更新 grade 字段 |
| `src/app/api/questions/grades/route.ts` | 新增年级列表 API（使用枚举值而非数据库查询） |

**执行命令：**

```bash
cd d:\Work_Area\AI\HomeLearn
npx prisma db push
```

**执行结果：**

```
Environment variables loaded from .env
Prisma schema loaded from prisma\schema.prisma
Datasource "db": PostgreSQL database "homelearn", schema "public" at "localhost:5432"
The database is already in sync with the Prisma schema.
Running generate... - Prisma Client
```

**注意事项：**
- 数据库已包含 `grade` 字段，之前创建的题目该字段值为 `null`
- 需要重新编辑题目并选择年级后保存，才能正确筛选

### 2026-05-11 16:51 | Question 模型添加 Recording 反向关联

**问题描述：**
```
Error: Prisma schema validation - (get-dmmf wasm)
Error code: P1012
error: Error validating field `question` in model `Recording`: The relation field `question` on model `Recording` is missing an opposite relation field on the model `Question`.
```

**解决方案：**

在 `Question` 模型中添加 `recordings` 关系字段：

```prisma
// 修改前
user            User              @relation(fields: [userId], references: [id], onDelete: Cascade)
subject         Subject           @relation(fields: [subjectId], references: [id])
versions        QuestionVersion[]
wrongQuestions  WrongQuestion[]
questionTopics  QuestionTopic[]
questionTags    QuestionTag[]
attachments     Attachment[]

// 修改后
user            User              @relation(fields: [userId], references: [id], onDelete: Cascade)
subject         Subject           @relation(fields: [subjectId], references: [id])
versions        QuestionVersion[]
wrongQuestions  WrongQuestion[]
questionTopics  QuestionTopic[]
questionTags    QuestionTag[]
attachments     Attachment[]
recordings      Recording[]        // 新增
```

## 功能开发记录

### 2026-05-12 | PDF 导入题库功能

**功能概述：**
支持将 PDF 文件中的题目自动解析并导入题库

**新增文件：**

| 文件路径 | 说明 |
|----------|------|
| `src/lib/services/pdf-parser.ts` | PDF 解析服务（文本提取） |
| `src/lib/services/question-identifier.ts` | AI 题目识别服务 |
| `src/app/api/pdf-parse/route.ts` | PDF 解析 API |
| `src/app/api/subjects/by-code/route.ts` | 按代码查询科目 API |
| `src/app/dashboard/questions/import/page.tsx` | PDF 导入前端页面 |

**依赖安装：**
```bash
npm install pdf-parse pdf-lib
npm install @ai-sdk/openai
```

**修改文件：**

| 文件 | 变更内容 |
|------|----------|
| `src/app/dashboard/questions/page.tsx` | 添加 PDF 导入入口按钮 |
| `src/lib/validators/question.ts` | 添加 FREE_RESPONSE/OTHER 题目类型 |
| `Doc/01_需求分析_完整版.md` | 添加 F5-1 PDF 导入题库功能需求 |

**功能流程：**
```
1. 用户上传 PDF 文件
2. 解析 PDF，提取文本
3. 调用 AI 识别题目结构
4. 预览编辑界面（人工校正）
5. 批量导入题库
```

**API 端点：**
- `POST /api/pdf-parse` - 解析 PDF 并识别题目
- `GET /api/subjects/by-code?code=math` - 按代码获取科目

**年级/科目识别模式：**
- 手动指定：用户选择年级 + 科目
- 自动识别：AI 自动推断（可选）

## Prisma 命令参考

```bash
# 同步 Schema 到数据库（开发环境）
npx prisma db push

# 创建正式迁移文件
npx prisma migrate dev --name <migration_name>

# 应用迁移（生产环境）
npx prisma migrate deploy

# 查看数据库状态
npx prisma db status

# 重置数据库（⚠️ 危险，会删除所有数据）
npx prisma migrate reset

# 生成 Prisma Client
npx prisma generate
```
