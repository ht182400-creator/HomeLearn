## 🚀 启动步骤

### 环境准备

```bash
# 1. 进入项目目录
cd d:/Work_Area/AI/HomeLearn

# 2. 安装依赖
npm install

# 3. 配置环境变量 (编辑 .env 文件)
# 必须配置项：
#   - DATABASE_URL: PostgreSQL 连接字符串
#   - NEXTAUTH_SECRET: 随机密钥 (可使用: openssl rand -base64 32)
#   - DEEPSEEK_API_KEY: DeepSeek API Key
#     申请地址: https://platform.deepseek.com/

# 4. 初始化数据库
npm run db:generate    # 生成 Prisma Client
npm run db:push        # 推送 Schema 到数据库

# 5. 启动开发服务器
npm run dev

# 6. 打开浏览器访问 http://localhost:3000
```

### Q5: 更新包含大量图片的题目时报错怎么办？

**时间：** 2026-05-12 15:10:00

**问题描述：** 更新包含大量图片的题目时失败，提示字段长度超限。

**原因：** 数据库中 `explanation` 字段的长度限制为 100000 字符，无法满足包含大量图片 Base64 数据的题目。

**解决方案：** 将 `explanation` 字段的长度限制增加到 500000 字符（与 `content` 字段保持一致）。

```prisma
// schema.prisma 中 Question 模型
explanation  String  @db.Text  // 原为 @db.VarChar(100000)，现改为 @db.Text
```

执行数据库迁移：
```bash
npm run db:push
```

### Q6: TypeScript 构建错误修复记录 (2026-05-12 21:32:00)

**问题描述：** 执行 `npm run build` 时出现多个 TypeScript 类型错误。

**根本原因：**

1. **NextAuth Session 类型未定义**
   - `session.user.id` 和 `session.user.role` 未在类型中声明

2. **Prisma 枚举值不一致**
   - Prisma Schema: `COMPOSITION`, `READING`, `LISTENING`
   - Zod 验证器: `COMPREHENSIVE`, `FREE_RESPONSE`, `OTHER`

3. **字段引用错误**
   - `prisma.child` → `prisma.childAccount`
   - `child.parentId` → `child.userId`
   - `child.name` → `child.nickname`

4. **grade 字段类型不匹配**
   - `gradeId` (string) 不能直接赋值给 `grade` (Grade枚举)

>
